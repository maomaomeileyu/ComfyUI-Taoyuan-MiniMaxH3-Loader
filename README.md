# 丨桃源专用-Minimax h3素材装载

给 ComfyUI 官方 MiniMax H3 节点用的素材装载前端：三个入口（图像 / 视频 / 音频）收素材，
按顺序自动连线到官方 H3 节点，并对音频、视频做时长筛查，不合格的素材不参与连线。

插件不封装官方节点，也不替代它——官方 `MiniMaxH3ReferenceToVideo` / `MiniMaxH3ImageToVideo`
该怎么用还怎么用，本插件只负责「把素材排好队、接对槽、把不合格的挡下来」。

## 要求

- ComfyUI **0.42 或更新**（要自带 `comfy_extras/nodes_minimax_h3.py` 里的官方 H3 节点）。
- 前端包 **1.55 或更新**（要支持 autogrow 动态输入）。
- 不装任何 pip 包：只用 ComfyUI 自带的 `comfy_api`，缩略图/预览另用 ComfyUI 已装好的
  `torch`、`Pillow`、`PyAV`。

## 安装

1. 把整个 `ComfyUI-Taoyuan-MiniMaxH3-Loader` 文件夹拷进
   `ComfyUI\custom_nodes\`。
2. 重启 ComfyUI。
3. 浏览器按 `Ctrl + F5` 强制刷新（前端 JS 会被缓存）。

没有额外依赖：只用 ComfyUI 自带的 `comfy_api`，不装 pip 包。

## 三个节点（分类：桃源/视频）

### 丨桃源专用-Minimax h3素材装载（主节点）

输入：图像、视频、独立音频、配套音频四组，每组都能**一个 batch 装多个**，也能**接多条线**。

「一个 batch 装多个」和「上游给的是列表」两种都能吃：上游如果是 ComfyUI 的列表输出
（例如一次加载多张图、多段视频），节点会把整个列表当成一组素材按顺序展开，不会只取第一条。
一个 slot 里同时有 batch 和列表时，先列表、后 batch，按到达顺序拼接。

输出：18 个素材口（参考图 1–9、参考视频 1–3、独立音频 1–3、配套音频 1–3）+ `提示词标签`
+ `报告JSON`，共 20 个。输出口是固定的，不随素材数量增减——这样连线不用等「素材数量定下来」
才画得出来。

它会自动把 18 个输出接到你指定的官方 H3 节点上。`提示词标签` 直接给出本次放行顺序的
`<Picture 1> <Video 1> <Audio 1>` 骨架，一般**不用**再单独放一个「H3提示词标签」节点。

### 丨桃源专用-H3素材校验

不接线，只想看一段素材合不合格时用。输入同上，输出 `报告JSON` + 人读摘要。
它是输出节点，接到工作流里就会执行。

### 丨桃源专用-H3提示词标签

按本次真正放行的素材顺序，吐出一段提示词骨架，例如：

```
<Picture 1> <Picture 2> <Video 1> <Audio 1> <Audio 2>
```

配对音轨的 `<Audio n>` 按官方规则排在对应 `<Video n>` 之前。把它接到官方节点的 `prompt`
上，再把标签后面补上你的描述即可，编号永远和实际素材对得上。

## 三种模式

面板上的「模式」下拉切换，切换后会自动重连：

| 模式 | 目标节点 | 接线 |
| --- | --- | --- |
| 全模态参考 | `MiniMaxH3ReferenceToVideo` | 图像 9 / 视频 3 / 独立音频 3 / 配套音频 3 |
| 首尾帧 | `MiniMaxH3ImageToVideo` | 图像 1 → `first_frame`，图像 2 → `last_frame`，其余不用 |
| 文生视频 | 不接素材 | 断开本插件建的所有线 |

「目标H3节点」下拉（在节点面板里，不是 widget）会按模式过滤候选；选「自动（就近）」则自动挑
画布上同类型、离本节点最近的一个。画布上有多个官方 H3 节点时，用这个下拉指定；插件建的线会覆盖该槽上原有的手接线。

## 顺序怎么定

- **同一组多条线**：按槽位号先后（`image_0`、`image_1`…），不是拖线时间。
  前端只允许按顺序扩张槽位，这是唯一可靠的口径。
- **一个 batch 里的多个素材**：按列表本身顺序展开。
- 依次是 图像 → 视频 → 独立音频，各自的槽位号都是 1 开始编号。

## 时长门槛与「屏蔽」到底是什么意思

默认：视频 2–15 秒，音频 ≥ 2 秒。面板上可以改。另外硬拦两条：视频少于 5 帧
（官方节点会直接抛 `ValueError`）、视频超过 15 秒。

被屏蔽的素材：

- **不占槽位**，后面的合格素材自动往前补，所以 `<Picture 1>` 这类编号不会断。
- 面板上标 `⛔` 并给出原因（比如「时长 0.50s < 最短 2.00s」）。
- 视频被屏蔽时，它同号的配套音频一起屏蔽。

**注意**：ComfyUI 的连线是静态的，插件没法在执行前「不画这条线」。所以屏蔽的实际表现是
**线还画在那里，但那一格输出 `None`，数据不流过**。官方节点对空槽是 `continue`，会安全跳过，
不会报错——这也是为什么编号能自动补位。

因为「接几根线」要等第一次执行后才知道真实数量，所以：

- 第一次接入素材时，面板按上限铺满（图像 9 条…），节点留在执行链路上；
- 跑一次之后，`executed` 事件把报告推回前端，插件立刻按真实数量把多余的线收掉。

正常用下来就是「接上 → 跑一次 → 线自己变成正确的数量」。

## 面板

节点上的中文面板（鱼酥那种分块栅格）显示：

- 顶部：当前模式徽标 + 状态行（`目标 #id · 已连线 n/m · 上游 k 条线 · v7`）；
- **目标H3节点** 下拉：列出画布上所有同模式的官方 H3 节点（`#id 标题`），选「自动（就近）」则由插件挑最近的；
- 底部：被拦截的条目（`⛔` + 原因）和告警。

上半部分的素材区**跟着模式变**：

| 模式 | 面板内容 |
| --- | --- |
| 全模态参考 | 参考图 3×3 九宫格（缩略图 + 序号）+ 参考视频三格（首帧、帧数、时长、有没有音轨）+ 配套音频三行 + 独立音频三行（真实波形 + 时长） |
| 首尾帧 | 「首帧 / 尾帧」两个大框，直接显示第 1、2 张图；提示图像 1→`first_frame`、图像 2→`last_frame`；另附独立音频 |
| 文生视频 | 一块说明，注明本模式不使用素材 |

面板宽度跟着节点走（可拖宽，最窄 300）；**高度不可拖**：每次重绘都把节点高度钉回面板内容的真实高度，
往下拉个子会立刻弹回去——做法照鱼酥插件的 `panelHeight()/fitNode()`：先 `node.size[1]=1` 再 `computeSize()`，
免得工作流里存的旧高度被喂回布局。素材变多（比如放满 9 张图）节点会自动变高，不需要手动拉。

素材的时长、尺寸、缩略图、波形全是**后端量出来的真实值**，不是前端猜的。这些数据跟着报告一起
回到面板，所以刷新页面或重开工作流后，上一次的结果仍在面板上（除非输入变了）。

> 每个节点只会挂**一个**面板。旧版本重开工作流会叠出两个，v7 已修：`onConfigure` 会先清掉旧面板再造新的。

### 点开就能预览

面板里的素材是**可以点的**（跑过一次之后）：

- 点参考图 → 弹层里按原比例放大（最长边 1024），点 `✕` 或按 `Esc` 或点空白处关闭；
- 点参考视频小格 → 弹层里用播放器直接放（`mp4`，h264，最长边 384，24fps，无声——音轨在配套音频里）；
- 点音频行 → 弹层里播放（`wav`，最长 60 秒）。

实现上不是把媒体塞进工作流 JSON（那会把图撑到几十 MB），而是执行时把放行的素材压一份到进程内存，
报告里只放一个短 token，前端点开时按 token 走本地 HTTP 路由取：

```
GET /ty_h3/image?t=<token>&i=<序号>
GET /ty_h3/video?t=<token>&i=<序号>
GET /ty_h3/audio?t=<token>&i=<序号>&k=audios|video_audios
```

进程里最多留 6 份、1 小时过期，ComfyUI 重启就没了（重启后点素材会提示「先运行一次」）。
代价是每次执行多约 0.5–1 秒做压缩，换来点击即看。

## 报告 JSON

`报告JSON` 输出和 websocket `executed` 里推给面板的是同一份：

```json
{
  "version": 1,
  "fps": 24.0,
  "thresholds": {"audio_min": 2.0, "video_min": 2.0, "video_max": 15.0},
  "items": {"images": [], "videos": [], "audios": [], "video_audios": []},
  "blocked": [{"kind": "video", "slot": 0, "source": "video_0", "duration": 0.5, "reason": "..."}],
  "warnings": [],
  "counts": {"images": 0, "videos": 0, "audios": 0, "video_audios": 0},
  "preview": {"token": "5f1c…", "fps": 24.0}
}
```

想接给别的节点做判断，直接读这个字符串。`items.*` 里还会带 `thumb`（JPEG data URL 缩略图，
视频取首帧）和 `peaks`（音频波形包络，48 个点），面板就是用它们画格子的。
`preview.token` 是预览路由的钥匙，见上面「点开就能预览」。

## 排查

浏览器控制台执行：

```js
__tyH3Audit()
```

会列出画布上每个素材装载节点的「想要接几根 / 实际接了几根 / 目标节点是谁」。

常见情况：

- **面板空白 / 完全没有自动连线 / 只有主节点能用**：多半是浏览器缓存了旧的 `web/js`
  （旧版导入路径写错，整个 JS 会 404 不执行）。按 `Ctrl + F5` 强制刷新；
  刷新后面板状态行会显示版本号 `v7`，看到 `v7` 才算加载到新版。
- **只能看到第一条素材**：上游给的是列表输出时，旧版节点会被按条调用、每次只见一条。
  现在三个节点都声明了 `is_input_list`，整个列表一次进城；若仍是 1 条，确认拷进去的是新版本
  （面板状态行显示 `v7` 即为新版），并且已经重启过 ComfyUI。
- **线没自动连**：确认「自动连线」开关是开的；确认目标节点存在且类型和模式匹配；
  点一下面板上的「重连」。工作流刚打开的头几秒会等图加载完再连，属正常。
  面板第二行会写「目标 #id · 已连线 n/m」，`n<m` 说明有槽没连上。
- **面板不显示时长**：还没跑过。跑一次就有了。
- **素材被误屏蔽**：把面板上的最短/最长秒数调小/调大，或检查上游给的是不是 24fps 的帧批次
  （视频口吃的是 IMAGE 帧批次，不是 VIDEO 类型）。

## 限制

- 素材顺序以槽位号为准；想让某张图排前面，就接到更小的槽位号上。
- 配套音频按**同号**配对（`ref_video_1` ↔ `ref_video_audio_1`），这是官方节点的硬规则。
- 首尾帧模式只用前两张图，多出来的会在报告里告警。
- 视频口输入是帧批次，时长 = 帧数 / `video_fps`（默认 24）。上游如果是别的帧率，
  把面板上的 `video_fps` 改对。
